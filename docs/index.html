PIXEL AGENTS

Your Claude Code agents, working in a pixel office.

An open-source mission-control desktop app. Every project is an office on one campus map; every agent is a character you can watch think, code, and ask for permission.

FEATURES

WHAT'S IN THE BOX

Real Claude Code sessions — same login, same config, same transcripts. Start in the app, resume in your terminal, or vice versa. Nothing is locked in.

CAMPUS VIEW

Register project folders as offices on one pannable pixel map. See at a glance who's working, who's waiting for you, and what each project costs today.

RICH CHAT AGENTS

Powered by the Claude Agent SDK: streamed markdown, tool cards with real diffs, Allow/Deny permission buttons, image paste, session resume.

TASK ORCHESTRATION

Shared task lists between you and your agents. Assign a task with one click — an agent spawns, works, logs discovered work, and checks it off when it truly finishes.

THE ASSISTANT

The rubber duck that talks back: a campus-wide orchestrator that reads project status, backlogs and spending, and dispatches agents to any office in plain language.

SPEND TRACKING

Exact costs from the SDK — not estimates. Per turn, per day, per project, live on each office's label.

ACHIEVEMENTS

Milestones for shipped tasks, parallel agents and streaks. Never for spend.

SELF-PORTRAIT

THE ART WAS DRAWN BY AGENTS

Every sprite on this page was drawn by Claude agents — authored as pixel arrays in TypeScript, rendered to a contact sheet, screenshotted, and self-critiqued in a loop until it looked right. The office they drew is the office they work in.
